# Оценка смещения траектории ракеты при морском старте

## Комбинирование линеаризации (метод малых возмущений) и Монте‑Карло

---

## Постановка задачи

**Условия:**
- Морская стартовая платформа в экваториальных водах Тихого океана
- Качка платформы: период **T = 8 с**, амплитуда наклона **A ≤ 2°** (0.035 рад)
- Задержка системы управления: **τ = 0.3 с** (от измерения угла до поворота сопла)
- Требуемая оценка: боковое смещение траектории на высоте **H = 10 км**
- Допуск точности выведения: **±1 км**

**Вопрос: можно ли использовать линеаризацию и Монте‑Карло вместе?**

**Ответ: Да.** Это стандартная схема *«linearized surrogate model + Monte Carlo uncertainty propagation»*, которая широко применяется в инженерной практике.

---

## Обоснование комбинирования

### Идея: линейная модель как быстродействующий суррогат внутри Монте‑Карло

Полный цикл Монте‑Карло на нелинейной 6DOF-модели ракеты требует тысячи прогонов численного интегрирования (Рунге–Кутта и т.д.), что вычислительно дорого. Выход — **разделить задачу на два уровня**:

```
┌───────────────────────────────────────────────────────────────┐
│  МОНТЕ‑КАРЛО (Метод D)                                        │
│  ┌─────────────────────────────────────────────────────────┐  │
│  │  ЛИНЕАРИЗОВАННАЯ МОДЕЛЬ (Метод A)                       │  │
│  │  Δy = f(φ, A, τ, ε_датчика, w)  — аналитическая ф‑ла  │  │
│  └─────────────────────────────────────────────────────────┘  │
│  Генерирует N выборок входных параметров → считает N×Δy       │
│  Строит гистограмму/CDF, оценивает 3σ, max, P(>1 км)         │
└───────────────────────────────────────────────────────────────┘
```

**Ключевой принцип:** линейная модель вычисляется за микросекунды, поэтому N = 10 000–100 000 прогонов Монте‑Карло занимают секунды, а не часы.

## Когда комбинирование корректно

### Необходимые условия

| Условие | Проверка для нашей задачи | Вывод |
|---|---|---|
| **Малые углы** | A = 2° = 0.035 рад; sin(2°) ≈ 0.0349, отличие от угла ~0.1% | ✅ Выполнено |
| **Локальная линейность динамики** | На активном участке (0…10 км, ~10–15 с) реакция системы управления близка к линейной при малых возмущениях | ✅ Выполнено |
| **Ограниченный диапазон параметров** | Все вариации (фаза, амплитуда, задержка) — малые добавки к номинальному полёту | ✅ Выполнено |
| **Независимость каналов управления** | Боковое отклонение рассматривается изолированно (без сильной кросс‑связи с тангажом/рысканьем) | ✅ В первом приближении |

### Физический смысл: почему линеаризация работает при 2°

Разложение функции смещения в ряд Тейлора вокруг номинальной траектории:

```
Δy(α) = Δy₀ + (∂Δy/∂α)|₀ · δα + O(δα²)

При α = 0.035 рад: член O(δα²) ~ (0.035)² = 0.0012  (0.1% от первого члена)
```

Нелинейными членами можно пренебречь.

## Построение линеаризованной модели

### Шаг 1 — Остаточная угловая ошибка из-за задержки (Метод C / передаточные функции)

Качка гармоническая: α(t) = A·sin(ωt), где ω = 2π/T = 2π/8 ≈ 0.785 рад/с

Задержка τ = 0.3 с даёт фазовый сдвиг:
```
φ = ω·τ = 0.785 · 0.3 ≈ 0.236 рад  (≈ 13.5°)
```

Остаточная некомпенсированная угловая ошибка:
```
θ_err(ψ) = A · sin(ψ + φ) - A · sin(ψ)  ≈  A · φ · cos(ψ)
```
где ψ — фаза качки в момент старта.

**Максимальное значение:** θ_err_max = A · sin(φ) ≈ A · φ = 0.035 · 0.236 ≈ **0.0082 рад** (при малых φ)

### Шаг 2 — Боковое смещение (Метод A / линеаризация)

Геометрическая оценка через малые углы:
```
Δy ≈ H · θ_err
```

**Расчёт:**
```
Δy_max ≈ 10 000 м · 0.0082 ≈ 82 м
```

### Шаг 3 — Вывод по допуску

```
82 м ≪ 1 000 м  →  смещением можно пренебречь при допуске ±1 км
```

## Какие неопределённости варьировать в Монте‑Карло

| Параметр | Распределение | Диапазон | Обоснование |
|---|---|---|---|
| **Фаза качки ψ** в момент старта | Равномерное U(0, 2π) | 0…2π рад | Момент старта не синхронизирован с фазой волны |
| **Амплитуда качки A** | Усечённое нормальное N(1°, 0.5°) | 0…2° | Реальная амплитуда варьируется со состоянием моря |
| **Задержка управления τ** | Нормальное N(0.3 с, 0.03 с) | 0.2…0.4 с | Небольшой разброс электронной задержки |
| **Ошибка датчика угла ε** | Нормальное N(0, σ_сенс) | σ_сенс ≈ 0.1° | Шум инерциальной платформы |
| **Боковой ветер w** | Нормальное N(0, σ_ветер) | σ_ветер = 5 м/с | Экваториальные условия |

## Алгоритм Монте‑Карло с линейной моделью

```python
import numpy as np

# Параметры задачи
H = 10000          # высота оценки, м
T_swing = 8.0      # период качки, с
omega = 2 * np.pi / T_swing
N = 100000         # число прогонов МК

# Генерация случайных входных параметров
rng = np.random.default_rng(seed=42)
psi   = rng.uniform(0, 2 * np.pi, N)          # фаза качки
A_deg = rng.normal(1.0, 0.5, N).clip(0, 2)    # амплитуда, градусы
A_rad = np.radians(A_deg)
tau   = rng.normal(0.30, 0.03, N).clip(0.2, 0.4)  # задержка, с
eps   = np.radians(rng.normal(0, 0.1, N))     # ошибка датчика, рад
wind  = rng.normal(0, 5, N)                   # ветер, м/с (упрощённо)

# Линеаризованная модель смещения
phi_delay = omega * tau                        # фазовый сдвиг от задержки
theta_err = A_rad * np.sin(phi_delay) * np.cos(psi) + eps

# Поправка от ветра (приближённо: w * t_flight / H * H)
# t_flight до H=10 км ≈ 30 с при среднем ускорении; боковой снос ≈ w * t²/(2*g_eff)
t_flight = 30.0                               # с, оценка времени набора 10 км
delta_y_wind = 0.5 * wind / 9.81 * t_flight  # упрощённая кинематика
# (точнее — через аэродинамические коэффициенты, здесь порядковая оценка)

delta_y = H * theta_err + delta_y_wind        # суммарное смещение, м

# Статистики
mean_y  = np.mean(delta_y)
std_y   = np.std(delta_y)
max_y   = np.max(np.abs(delta_y))
p3sigma = np.percentile(np.abs(delta_y), 99.73)  # 3σ-квантиль
prob_exceed = np.mean(np.abs(delta_y) > 1000)     # P(|Δy| > 1 км)

print(f"Среднее смещение:     {mean_y:.1f} м")
print(f"Ст. отклонение:       {std_y:.1f} м")
print(f"3σ-квантиль:          {p3sigma:.1f} м")
print(f"Максимум:             {max_y:.1f} м")
print(f"P(|Δy| > 1 км):       {prob_exceed:.6f}")
```

## Какие выходы оценивать

| Метрика | Формула | Практическое значение |
|---|---|---|
| **Математическое ожидание** E[Δy] | `mean(Δy)` | Систематическое смещение траектории |
| **3σ-граница** | `percentile(|Δy|, 99.73%)` | Охватывает 99.7% запусков |
| **Максимум** | `max(|Δy|)` | Абсолютный worst-case |
| **P(|Δy| > 1 км)** | `mean(|Δy| > 1000)` | Вероятность нарушения допуска |
| **Гистограмма Δy** | распределение | Визуализация формы распределения |

**Для вывода о допустимости:** достаточно убедиться, что **3σ < 1 000 м**.

## Ограничения метода

### Когда необходимо возвращаться к нелинейному численному интегрированию

| Ситуация | Почему линейная модель не подходит |
|---|---|
| **Насыщение привода TVC** | При ограничении угла/скорости отклонения сопла реакция нелинейна; линейная модель занижает хвост распределения |
| **Большие возмущения** (A > 5–7°) | Нелинейные члены sin(α) ≠ α становятся значимыми (ошибка > 1%) |
| **Аэроупругость** | Связь форм колебаний конструкции с аэродинамикой нелинейна |
| **Широкий диапазон условий** | При сильном ветре (> 20 м/с) или сильном волнении нарушается предположение о малых возмущениях |
| **Строгое доказательство безопасности** | Монте‑Карло даёт статистическую оценку, а не детерминированную гарантию |
| **Фаза первоначального отрыва от стола** | В первые ~0.5–1 с динамика нелинейна из‑за конечной скорости нарастания тяги и взаимодействия с опорами |

### Критерий возврата к Рунге–Кутте

Используйте нелинейное интегрирование, если хотя бы одно условие выполнено:
- амплитуда возмущений θ > 5° (нелинейность sin ~ 0.4%)
- требуется траектория по времени, а не только конечное отклонение
- задача сертификационная (необходимы верифицированные модели)

## Используемые методы и литература

| Метод | Применение | Источник |
|---|---|---|
| **A — Линеаризация / малые возмущения** | Аналитическая формула Δy | Greensite A.L. (1955); [5] в репозитории |
| **C — Передаточные функции / запаздывание** | Оценка θ_err из-за τ | Smith O.J.M. (1957); [8] в репозитории |
| **D — Монте‑Карло** | Статистическое распространение неопределённости | Metropolis & Ulam (1949); [9] в репозитории |

Связка **A + C + D** позволяет получить вероятностную оценку смещения без полноценного численного интегрирования 6DOF-модели.
