# Выбор метода для задачи морского старта

## Постановка задачи

Морская стартовая платформа находится в экваториальных водах Тихого океана. Параметры условий пуска:

| Параметр | Значение |
|---|---|
| Период качки платформы | 8 с |
| Амплитуда наклона платформы | до 2° |
| Задержка управления (измерение → отклонение сопла) | 0,3 с |
| Высота оценки смещения | 10 км |
| Требование к точности выведения на орбиту | ±1 км |

**Вопросы:**
1. Насколько (в метрах) сместится траектория ракеты на высоте 10 км из-за наклона платформы в момент старта?
2. Можно ли пренебречь этим смещением при выведении спутника на орбиту (точность ±1 км)?
3. Какие методы применять для вывода на орбиту?

---

## Рекомендуемые методы

### 1. Оценка смещения траектории (до 10 км): Метод A + Метод C

#### Метод A — Линеаризация / малые возмущения

Для оценки смещения траектории на начальном участке полёта применяется **метод линеаризации** (метод малых возмущений). При малых углах (2° ≈ 0,035 рад) линейное приближение достаточно точно.

**Шаг 1. Учёт задержки управления (Метод C — передаточные функции с запаздыванием)**

Качка гармоническая: α(t) = A·sin(ωt), где

```
ω = 2π / T = 2π / 8 ≈ 0,785 рад/с
```

Чистое запаздывание τ = 0,3 с даёт фазовый сдвиг:

```
φ = ω·τ ≈ 0,785 · 0,3 ≈ 0,236 рад (≈ 13,5°)
```

Остаточная угловая ошибка из-за задержки:

```
θ_err ≈ A · sin(φ) ≈ A · φ  (для малых φ)
θ_err ≈ 0,0349 · 0,236 ≈ 0,0082 рад ≈ 0,47°
```

**Вывод:** из-за задержки 0,3 с система управления не успевает скомпенсировать ~0,5° наклона.

**Шаг 2. Боковое смещение на высоте H (линейная кинематика)**

```
Δy ≈ H · θ_err = 10 000 · 0,0082 ≈ 82 м
```

**Шаг 3. Сравнение с допуском**

```
82 м << 1 000 м  ⟹  смещением можно пренебречь
```

---

### 2. Статистическое обоснование (Метод A + Метод D: Монте-Карло)

Один расчёт отвечает лишь для одной фазы качки. Для полного статистического анализа применяется **связка: линеаризованная модель + Монте-Карло**.

#### Алгоритм

1. Вычисляем линейные коэффициенты влияния начального угла и угловой скорости на боковое смещение:

```
Δy(H) ≈ K_θ · θ₀ + K_ω · θ̇₀
```

2. Задаём случайные входные параметры:
   - фаза качки: φ ~ U(0, 2π)
   - амплитуда: A ≤ 2° (фиксированная или случайная)
   - при необходимости: разброс задержки τ, шум датчика

3. Для каждого прогона:

```
θ₀ = A · sin(φ),   θ̇₀ = A · ω · cos(φ)
```

4. Собираем статистику по N = 500–2000 прогонам:
   - максимум: max|Δy|
   - 3σ — инженерная гарантия
   - вероятность: P(|Δy| > 1 км)

#### Когда применять

| Условие | Применимость |
|---|---|
| Малые углы (≤ 2°) | ✅ Линеаризация корректна |
| Нет насыщения TVC | ✅ Линейная модель точна |
| Цель — оценка статистики | ✅ Монте-Карло подходит |
| Насыщение привода TVC | ⚠️ Требуется нелинейная модель |
| Гарантированный worst-case | ⚠️ Монте-Карло даёт оценку, не гарантию |

---

### 3. Валидация: численное интегрирование (Метод B — Рунге-Кутта)

Для **верификации** результатов линейной модели используется **численное интегрирование** (метод Рунге-Кутта 4-го порядка). Это наиболее строгий метод, но требующий больших вычислительных затрат.

**Применение:**
- Строится полная 3/6DOF модель ракеты
- Интегрируются уравнения движения с шагом Δt ≤ 0,01 с
- Сравниваются результаты с оценкой линейной модели

**Вывод:** численное интегрирование служит эталоном для проверки, но не является основным методом инженерной оценки на стадии выбора требований.

## Для вывода на орбиту: методы и процедуры

При переходе от оценки смещения к задаче **обеспечения точности выведения на орбиту** применяется полная система GNC (Guidance, Navigation, Control — наведение, навигация, управление) с замкнутым контуром.

### Схема методов

```
┌──────────────────────────────────────────────────────────────┐
│              СИСТЕМА GNC ДЛЯ ВЫВОДА НА ОРБИТУ                │
├──────────────────────────────────────────────────────────────┤
│  NAVIGATION (навигация)                                      │
│  • INS (инерциальная навигационная система) — основной       │
│    измеритель угла, угловой скорости, ускорений              │
│  • GNSS (GPS/ГЛОНАСС) — коррекция накопленной ошибки INS     │
│  • Фильтр Калмана — оптимальное слияние INS + GNSS           │
├──────────────────────────────────────────────────────────────┤
│  GUIDANCE (наведение)                                        │
│  • Итеративное наведение (IG/PEG — Powered Explicit Guidance)│
│  • Коррекция ошибки орбиты в реальном времени                │
│  • Пересчёт команды по управлению вектором тяги (TVC)        │
├──────────────────────────────────────────────────────────────┤
│  CONTROL (управление)                                        │
│  • Линейно-квадратичный регулятор (LQR) / PID               │
│  • Учёт задержки 0,3 с: компенсатор Смита или предиктор      │
│  • Замкнутый контур по углу/угловой скорости                 │
└──────────────────────────────────────────────────────────────┘
```

### Метрики для оценки точности выведения

| Метрика | Описание | Целевое значение |
|---|---|---|
| Ошибка по высоте орбиты | Δh | ±1 км |
| Ошибка по наклонению | Δi | < 0,05° |
| Ошибка по скорости | ΔV | < 1 м/с |
| Вероятность успешного выведения | P | > 0,99 |
| 3σ бокового смещения | 3σ(Δy) | < 1 000 м |

### Процедуры компенсации начальных возмущений

1. **Предстартовая выставка INS:** гироскопическое выравнивание по INS с учётом качки (алгоритм ZUPT).
2. **Коррекция по GNSS на участке выведения:** обновления фильтра Калмана каждые 0,1–1 с.
3. **Компенсация задержки управления:** предиктор Смита или упреждающее управление по модели качки.
4. **Замкнутый контур наведения (PEG/IG):** пересчёт команды вектора тяги каждые 0,5–2 с на основе текущего вектора состояния орбиты.

## Итоговые рекомендации

### Для оценки смещения (до 10 км):

| Этап | Метод | Обоснование |
|---|---|---|
| Быстрая оценка порядка | **Линеаризация (Метод A)** | Простота, аналитическое выражение, достаточная точность при малых углах |
| Учёт задержки управления | **Передаточные функции (Метод C)** | Явный учёт фазового сдвига на частоте качки |
| Статистическое подтверждение | **Монте-Карло (Метод D)** | Анализ по всем фазам качки, оценка P(|Δy| > 1 км) |
| Верификация | **Численное интегрирование (Метод B)** | Эталонный расчёт для проверки линейной модели |

### Для вывода на орбиту (точность ±1 км):

| Подсистема | Метод / инструмент |
|---|---|
| Навигация | INS + GNSS + фильтр Калмана |
| Наведение | Powered Explicit Guidance (PEG) |
| Управление | LQR/PID + компенсатор задержки (Smith Predictor) |
| Верификация | 6DOF симуляция + Монте-Карло (500–2000 прогонов) |

### Вывод

Смещение траектории из-за качки платформы (~82 м на высоте 10 км) **пренебрежимо мало** по сравнению с требованием ±1 км. Для гарантированного вывода на орбиту необходима полная система GNC с замкнутым контуром на основе INS/GNSS, обеспечивающая дополнительную коррекцию ошибки выведения в реальном времени.
